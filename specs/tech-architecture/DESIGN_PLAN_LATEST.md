# Design Plan — Core Rental (DESIGN_PLAN_LATEST)

> Source of truth: `docs/design/tropical_tech/DESIGN.md` (tokens) + the four `docs/design/*/code.html` mockups + ruled deltas C1–C6.
> Decisions: #8 (light only), #14 (Tailwind), D6 (fonts), D2 (metadata), #18 (brand), #24 (a11y), #31 (images).

## Brand

- Name: **Core Rental** (decision #18) — tagline "Your Bali Office, Delivered." (metadata/OG, D2)
- "Moni's Workspace" is retired; store + home headers already carried "Core Rental"

## Design tokens (from tropical_tech/DESIGN.md → Tailwind v4 theme)

- Material-3-derived palette: primary `#006767`, primary-container `#008282`, secondary `#376757`, secondary-container `#baeed9`, tertiary `#974400`, tertiary-container `#bb580d`, surface scale (`#f8f9fa` → `#e1e3e4`), on-surface `#191c1d`, on-surface-variant `#3d4949`, outline/outline-variant, error scale
- Light mode only — `dark:` variants are **not ported** (decision #8); tokens retained for a future dark pass
- Typography: **Plus Jakarta Sans** (display/headline/body) + **Manrope** (labels); sizes per DESIGN.md (display-lg 48/56, headline-lg 32/40, headline-md 24/32, body-lg 18/28, body-md 16/24, label-md 14/20, label-sm 12/16)
- Spacing: 8px unit, gutters (16/24/32/40), section-gap 80, container-max 1280
- Icons: **Material Symbols Outlined** — the `FILL` axis (`font-variation-settings: 'FILL' 1`) is load-bearing for filled states; **fonts strategy (D6): text via `next/font` (self-hosted), Material Symbols via `<link>`** to protect the FILL axis

## Shared UI primitives (`shared/ui`)

`ProductCard` (builder panel + store grid) · `PriceTag` (single IDR home) · `Button` (a11y baseline: focus-visible, aria) · `LoadingSkeleton` (matches root `loading.tsx` aesthetic) · `ErrorState` (friendly copy + retry, wired to query.refetch)

## Imagery (decision #31)

- 7 **hero products** keep Google mockup URLs (`lh3.googleusercontent.com/aida-public/…`)
- ~48 new products → deterministic on-brand **SVG placeholder tiles** (category-colored, Material icon, name + IDR price), generated by `scripts/generate-catalog.ts`
- `onError` fallback → local SVG placeholder on any image failure (E2E N7)

## Metadata (D2)

- Layout: title "Core Rental — Your Bali Office, Delivered.", description, theme-color, favicon
- OG: og:title, og:description, og:image (social-share friendly — WhatsApp/Telegram/Slack)
- Per-page titles: Builder / Store / Summary

## Accessibility baseline (decision #24)

Semantic HTML (real buttons/nav/headings) · `aria-label`/`aria-pressed` · visible `focus-visible` rings · keyboard-operable canvas slots (tab + Enter/Space; arrow keys for quantity) · labeled form inputs with `aria-invalid`/`aria-describedby` (G3) · Material-3 palette already contrast-aware.
